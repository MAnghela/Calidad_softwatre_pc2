# ERP Retail Control

Proyecto académico de un sistema ERP mínimo para una pequeña empresa comercial.

## Requisitos

- Python 3.12+
- Flask
- Flask-SQLAlchemy

## Ejecutar

```bash
cd erp_retail_control
python -m pip install -r requirements.txt
python run.py
```
